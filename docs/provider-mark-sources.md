# Provider mark sources

TokenForge uses compact provider marks only to identify the selected model’s original publisher. The marks remain the property of their respective owners and are shown with the provider name in adjacent accessible text.

| Provider family | Source | Intended use |
| --- | --- | --- |
| Qwen | [Qwen Studio, Alibaba Cloud](https://qwen.ai/home) | Owner-published horizontal Qwen mark, adapted as a compact dark-surface provider identity. |
| Kimi | [KIMI Brand Guidelines, Moonshot AI](https://moonshotai.github.io/Branding-Guide/) | Owner-published dark-surface KIMI mark; the guide explicitly presents the primary logo and icon variants. |
| Claude / Anthropic | [Simple Icons: Anthropic](https://simpleicons.org/?q=anthropic) (CC0 artwork data) | Lightweight static vector used with adjacent publisher text. The Anthropic mark remains the property of Anthropic. |
| Gemini / Google | [Simple Icons: Google](https://simpleicons.org/?q=google) (CC0 artwork data) | Lightweight static vector used with adjacent publisher text. The Google mark remains the property of Google. |
| DeepSeek | [Simple Icons: DeepSeek](https://simpleicons.org/?q=deepseek) (CC0 artwork data) | Lightweight static vector used with adjacent publisher text. The DeepSeek mark remains the property of DeepSeek. |
| Z.AI, xAI, OpenAI, Mistral, MiniMax, and Meta | Text-forward compact mark | A lightweight text identifier is used until an owner-published compact mark and applicable use guidance are recorded. |

Other publisher identities use text-forward marks until an owner-published compact mark and applicable use guidance are recorded. This avoids presenting third-party composite artwork as an official source asset.
